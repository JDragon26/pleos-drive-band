# 기획서 — 드라이브 밴드

> 접수양식(DOCX)에 옮겨 적는 원고. [가정] 표시 숫자는 근거 자료로 바꿀 것.

## 1. 앱 개요
- **앱 이름:** 드라이브 밴드
- **한 줄 소개:** 달리면 차가 작곡하고, 서 있으면 차가 악기가 된다
- **카테고리:** 음악/엔터테인먼트
- **대상:** 출퇴근 운전자, 드라이브·여행 가족, 충전·대기 중인 운전자와 아이, 숏폼 콘텐츠를 즐기는 2030

## 2. 문제
- 매일 같은 출퇴근길, 같은 플레이리스트. 운전 시간은 그냥 흘러가는 시간이다.
- 전기차 충전(20~40분), 픽업 대기, 휴게소 휴식 때 차 안에서 할 게 휴대폰뿐이다.
- 차는 운전자의 모든 움직임을 알고 있지만, 그 데이터는 경험으로 돌아오지 않는다.

## 3. 해결 — 기어에 따라 두 모드가 자동으로 바뀐다
**주행 중: 드라이브 송 (차가 작곡)**
1. 속도·핸들·깜빡이·와이퍼·브레이크·탑승 인원을 **실시간 작곡 재료**로 사용
2. 정해 둔 화음 진행·5음 음계 안에서만 음을 골라 **어떻게 운전해도 듣기 좋게**
3. 출발하면 자동 작곡·녹음, 도착하면 **"10/29 퇴근길 · 비 · 23분"** 곡으로 저장
4. 곡은 차 상태 기록만 저장 → 다시 들을 때 똑같이 재합성 (용량 수 KB)
5. 화면 조작 없음 — 소리만으로 즐긴다

**정차(P) 중: 카 밴드 (내가 연주)**
1. 차의 조작부를 그대로 **악기 컨트롤러**로: 브레이크=킥, 깜빡이=스네어·하이햇, 핸들=심벌
2. **노래 따라 연주** — 리듬 게임(판정·점수·콤보·별)
3. **자유 연주** — 드럼 / 기타(핸들 각도로 코드 선택)
4. **박자 맞추기** — 차량 신호 지연을 측정해 차종마다 판정을 자동 보정
5. P에서 벗어나면 연주는 즉시 꺼지고 드라이브 송으로 돌아간다

## 4. 차량특화성
휴대폰은 핸들 각도·깜빡이·와이퍼·브레이크·탑승 인원을 모르고, 페달도 없다. 드라이브 송의 곡은 **그 차, 그 길, 그 날씨, 함께 탄 사람**으로만 만들어지고(비 오는 날엔 빗길 화음과 드럼, 가족이 타면 합주), 카 밴드는 운전에 쓰던 실제 조작부가 악기가 된다. 기어 상태로 "주행 중엔 듣기만, 정차 중엔 연주"를 앱이 스스로 나눠 안전 기준도 지킨다.

## 5. SDK 활용
Vehicle – Gear(모드 전환·자동 녹음), Brake pedal, Steering angle, Turn signal, Wiper, Seat occupancy / AAOS PERF_VEHICLE_SPEED(템포)

## 6. 화면
- **주행 중:** "드라이브 송 · 작곡 중 / ♪ 112 BPM / 빗길 비트 · 3인 합주" (조작 없음)
- **정차(P):** 위쪽 탭 4개
  - 드라이브 송 — 방금 저장한 곡, 미리 듣기, 자동 작곡 스위치, 내 곡 목록(▶ 다시 듣기)
  - 노래 따라 연주 — 내려오는 노트, 판정·점수·콤보, 결과 별
  - 자유 연주 — 드럼/기타
  - 박자 맞추기

## 7. 사업성
- **MAU 추정:** 탑재 차량 [가정] 10만 대 × 사용률 [가정] 12% ≈ 1.2만 MAU
- **수익 모델:** ① 사운드 테마 구독(재즈·로파이·오케스트라) ② 곡 팩 판매 ③ 제조사·아티스트·브랜드 협업(신차 고유 테마, 신곡 홍보 곡) ④ 충전소·지역 관광 제휴(해안도로 테마곡, 충전소 랭킹 이벤트)
- **바이럴:** "내 퇴근길이 만든 노래", "브레이크로 드럼 치기" 숏폼 영상 공유
- **확장:** 경로 지도와 함께 곡 공유, 연말 "올해의 드라이브 앨범", 사용자 채보 공유, 동승자 합주(뒷좌석 화면)

## 8. 개발 현황 (2026-10-29)
- 두 모드 모두 동작: 실시간 작곡·녹음·저장·다시 듣기 / 리듬 게임·자유 연주·박자 맞추기
- release APK·소스·README·자동 시연 스크립트, 단위 테스트 15개
- 에뮬레이터: 오디오 끊김 0, 자동 연주 58노트 중 56 적중, 측정 지연 브레이크 약 30ms·깜빡이 약 50ms

## 9. PT 시연 (3분)
1. 출발 → 음악 시작, 핸들 좌우로 멜로디가 따라 움직임
2. 고속 → 템포 업, 깜빡이 → 똑딱 박자, 와이퍼 → 빗길 드럼
3. 도착(P) → "오늘의 곡" 저장 → 다시 듣기
4. 노래 따라 연주 → 심사위원이 직접 브레이크·깜빡이로 연주 → 별
5. 다시 출발 → 연주가 꺼지고 드라이브 송으로 전환
