# 드라이브 밴드

**달리면 차가 작곡하고, 서 있으면 차가 악기가 된다**

기어에 따라 두 모드가 자동으로 바뀝니다.
- **주행 중 — 드라이브 송:** 속도·핸들·깜빡이·와이퍼·브레이크·탑승 인원으로 그 순간에만 나오는 곡을 실시간 작곡하고, 도착하면 "오늘의 곡"으로 저장합니다. 화면 조작은 없습니다.
- **정차(P) 중 — 카 밴드:** 브레이크·깜빡이·핸들로 연주합니다. 노래 따라 연주(리듬 게임), 자유 연주(드럼·기타), 박자 맞추기가 있습니다. P에서 벗어나면 연주는 바로 꺼집니다.

모든 소리는 앱 안에서 합성합니다(음원 파일·저작권 없음).

## 주요 기능
### 드라이브 송 (주행 중)
| 차 | 음악 | 차량 데이터 |
|---|---|---|
| 속도 | 템포 72~128 BPM, 빠를수록 멜로디가 촘촘 | 차속 |
| 핸들 | 멜로디 높낮이 (왼쪽 ↓ 오른쪽 ↑) | 핸들 각도 |
| 방향지시등 | 박마다 "똑딱" + 방향 쪽 꾸밈음 | 방향지시등 |
| 와이퍼 | 드럼 비트 + 빗길 화음 진행(vi–IV–I–V) | 와이퍼 |
| 브레이크 | 멜로디 쉼표, 잔향이 커짐 | 브레이크 |
| 탑승 인원 | 1명 피아노+패드 → 2명 +베이스 → 3명 +아르페지오 → 4명 +벨 | 좌석 탑승 |

- **자동 작곡·녹음:** 출발하면 시작, 도착하면 저장 (20초 미만은 저장 안 함, 최근 30곡)
- **다시 듣기:** 곡은 "작곡기 seed + 칸마다 읽은 차 상태"만 저장하고 재생할 때 다시 합성 (30분 곡 수 KB)
- **미리 듣기:** 정차 중 지금 차 상태로 바로 연주
- 오디오 포커스를 지켜 다른 미디어·안내와 충돌하지 않음

### 카 밴드 (정차 중)
| 기능 | 설명 | 차량 데이터 |
|---|---|---|
| 노래 따라 연주 | 직접 만든 곡 "첫 시동"(100 BPM, 17마디), 노트가 내려오면 해당 조작, 완벽/좋아요/놓침 판정·점수·콤보·별 3개 | 브레이크, 방향지시등, 핸들 각도 |
| 자유 연주 – 드럼 | 브레이크=킥, 왼쪽 깜빡이=스네어, 오른쪽=하이햇, 핸들=심벌 | 〃 |
| 자유 연주 – 기타 | 핸들 각도로 코드 선택(F·C·G·Am), 브레이크=스트럼, 깜빡이=뮤트 커팅 | 〃 |
| 박자 맞추기 | 메트로놈 8박에 브레이크 → 신호 지연+반응 중앙값으로 판정 보정 자동 설정 | 브레이크 |

## 실행 방법
1. 에뮬레이터 실행 후 `adb install -r -g apk/설계3.5팀_드라이브밴드_release.apk`
2. Virtual Console: `adb forward tcp:8088 tcp:8088` → `http://127.0.0.1:8088`
3. 전체 자동 시연: 앱을 켜 두고 `pwsh -File tools/demo_driveband.ps1 -Auto`
   - 1부 드라이브 송: 출발 → 핸들 멜로디 → 고속 템포 → 깜빡이 → 비 → 브레이크 → 도착 저장 → 4인 합주 → 다시 듣기
   - 2부 카 밴드: 노래 따라 연주(채보대로 자동 연주) → 자유 연주 드럼 → 다시 출발하면 드라이브 송으로 전환
   - 부분만: `tools/demo_drivesong.ps1`, `tools/demo_carband.ps1`("노래 따라 연주" 탭에서)
4. 반응 속도 측정: "노래 따라 연주" 탭에서 `pwsh -File tools/measure_latency.ps1` (에뮬레이터 측정 브레이크 약 30ms, 깜빡이 약 50ms)
5. 에뮬레이터 소리는 PC 스피커로 나옵니다.

## 테스트 환경
- Android Studio 2026.2 / Gradle 8.11.1 / **JDK 21**, Pleos Vehicle SDK 2.3.2, `android.car`(차속)
- 단위 테스트: `gradlew testDebugUnitTest` — 15개
  - 드라이브 송 6개: 템포, 음계·화음 구성음, 핸들↔높낮이, 브레이크·와이퍼·동승자·깜빡이 악기, 녹음=다시 듣기 동일, 곡 제목
  - 카 밴드 9개: 판정 창, 조작부 구분, 놓침·콤보, 지연 보정, 중복 판정, 별, 박자 맞추기 2개, 채보 검사

## APK
`apk/설계3.5팀_드라이브밴드_release.apk` (release 서명)

## 권한
`pleos.car.permission.CAR_DRIVE`(기어·브레이크·핸들) · `CAR_LIGHTS`(방향지시등) · `CAR_SEATS`(탑승 인원) · `CAR_WINDOWS`(와이퍼) · `android.car.permission.CAR_SPEED`(차속)

## 알려진 사항
- 차속을 못 읽으면 템포가 72 BPM 으로 고정되고 나머지는 그대로 동작합니다.
- 비상등은 표준 권한(CAR_EXTERIOR_LIGHTS)이 일반 앱에 허용되지 않아 쓰지 않습니다.
- 에뮬레이터에서 차량 신호를 받는 다른 앱이 여러 개 떠 있으면 신호가 늦어져 판정이 밀립니다. 시연 전 다른 앱을 종료하세요.
- 판정 시각은 시스템 시계 기준입니다(에뮬레이터 오디오 재생 위치가 약 5% 밀리는 문제 회피).
- 카 밴드 입력은 앱의 차량 연결(CarHub)을 같이 씁니다. Vehicle 을 따로 만들어 release 하면 같은 앱의 다른 구독까지 끊깁니다(2026-10-29 확인).
- 에뮬레이터에서는 날짜가 Virtual Console 시각을 따릅니다.
